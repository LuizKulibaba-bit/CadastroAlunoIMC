Este projeto consiste em um sistema de cadastro de alunos desenvolvido em Java utilizando ArrayList. A classe Aluno representa cada aluno e armazena informações como código, nome, email, peso, altura e sexo, além de calcular o IMC. A classe ControlaAluno é responsável por gerenciar a lista de alunos, realizando operações de cadastro, busca, listagem e exclusão. A classe Interface faz toda a interação com o usuário através do console, exibindo menus e validando os dados digitados. Por fim, a classe Principal controla o fluxo do sistema e conecta todas as classes. O projeto utiliza conceitos importantes de Programação Orientada a Objetos, como encapsulamento, composição, sobrescrita de métodos e uso de coleções dinâmicas com ArrayList.
